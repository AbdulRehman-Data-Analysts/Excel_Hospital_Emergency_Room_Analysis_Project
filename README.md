# Excel_Hospital_Emergency_Room_Analysis_Project
Hospital Room Analysis &amp; Management System is an Excel-based healthcare analytics project that analyzes patient flow, ER visits, admissions, waiting time, and satisfaction scores using dashboards, Pivot Tables, KPIs, and interactive visualizations to generate meaningful insights.

🏥 Hospital Room Analysis & Management System

A professional **Excel-based Hospital Data Analysis & Management Dashboard** designed to analyze patient activity, emergency-room trends, waiting times, admissions, and patient satisfaction.

 📊 Key Analysis

* 👥 **952 Total Patients Analyzed**
* 🏥 **502 Patients Admitted**
* 📈 Daily Emergency Room Patient Trends
* ⏱️ Average Patient Waiting Time Analysis
* ⭐ Patient Satisfaction Score Analysis
* 📊 Admission vs. Non-Admission Analysis
* 📌 Interactive Pivot Reports & Dashboard Visualizations

### 🛠️ Tools & Techniques

**Microsoft Excel | Pivot Tables | Data Analysis | Dashboard | Charts | KPIs**

This project demonstrates how Excel can transform hospital data into **clear, meaningful insights** that help understand patient flow, waiting times, admissions, and overall patient experience.
